# 실제 장치 통합 테스트 체크리스트

1. Android Studio에서 앱 빌드 성공 확인
2. Microchip Studio Stage 5 펌웨어 빌드 성공 확인
3. 휴대폰에서 Bluetooth 모듈 페어링
4. 앱에서 장치 연결 후 18자리 D 패킷 수신 확인
5. 개발자 도구에서 물/사료 무게와 센서 상태 확인
6. 개발자 도구에서 물 펌프, 사료 모터, 덮개, 약통 A/B 개별 테스트
7. 시연 모드 3회 예약 실행 및 기록 저장 확인
8. 생활 모드 예약 1건 등록 → 장치 동기화 → 휴대폰 Bluetooth 해제 → 예약 시간에 ATmega 단독 실행 확인
9. ATmega 전원 재인가 → 앱 재연결 → 시간/예약 자동 재동기화 확인
10. 기록 화면 카드/오늘 요약/공유/삭제 확인

주의: 생활 모드 실제 실행 기록은 현재 ATmega가 실행 이벤트를 앱에 별도로 보내지 않으므로 앱에서 확정 기록하지 않습니다.
