# 장치 없이 지금 확인할 수 있는 테스트

1. 앱 실행
2. `개발자 도구 · 센서 / 모터 테스트` 진입
3. `장치 없이 시뮬레이션` 선택
4. 홈 화면 센서 값이 채워지는지 확인
5. 물 목표량 증가/감소, 덮개 열기/닫기, 보충완료, RESET 확인
6. 개발자 화면에서 M1~M5 버튼을 눌러 상태와 로그 변화 확인
7. 생활 예약을 현재 시각 + 1분으로 등록하고 생활 모드 ON
8. 시뮬레이션 상태에서 예약 시각이 되면 기록 화면에 `생활 급식` 카드가 생기는지 확인
9. 시연 급식을 짧은 간격으로 실행하여 시연 기록 저장 확인

시뮬레이션은 앱 로직/UI 검증용이며 실제 센서/모터 동작을 보증하지 않습니다.
