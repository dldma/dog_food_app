# Stage 2 변경사항 — 보호자용 홈 UI

기준: `dog_food_kotlin_stage1_git`

## 이번 단계에서 바꾼 것

- 홈 화면을 일반 보호자가 한눈에 이해할 수 있는 대시보드 형태로 재구성
- 컬러를 진한 파랑 중심에서 반려동물 케어 앱에 맞는 딥 그린/뉴트럴 톤으로 변경
- 장치 전체 상태, 다음 급식, 물/사료, 약 A/B, 오늘의 추정 섭취량을 우선 배치
- "추정 섭취"라는 표현을 화면에서 명확히 사용
- 시연 예약 3회 정보를 카드 형태로 정리
- 기존 수동 제어는 삭제하지 않고 `장치 빠른 제어`로 하단에 유지
- 블루투스 연결 시 연결 배지를 초록색으로 표시
- 물 유지 설정값에 `g` 단위를 표시
- 급식 일정은 한 줄에 몰리지 않도록 2줄 형태로 표시

## 동작 로직

- Bluetooth 프로토콜과 ATmega 명령은 변경하지 않음
- 시연 예약(+1분 / +4분 / +7분), TTS, 기록 저장 로직 유지
- 기록/설정 Activity 유지

## 다음 단계 예정

1. 앱 내 `생활 / 시연 / 개발자` 모드 구조
2. 개발자용 센서/모터 테스트 화면 통합
3. 생활 모드 예약 화면
4. 설정 화면(반려견 정보, 자동 계산/직접 급식량) 개선
5. 기록 화면 개선
