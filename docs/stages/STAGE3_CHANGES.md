# Stage 3 변경사항

## 개발자 도구 통합

- 홈 화면 하단에 `개발자 도구 · 센서 / 모터 테스트` 진입 버튼 추가
- 기존 블루투스 연결을 그대로 공유하는 전체 화면형 개발자 패널 추가
- 실시간 센서 표시
  - 물 로드셀 / 사료 로드셀
  - 물통 감지 / 사료 감지
  - 덮개 상태
  - 약통 A/B 잔여량
  - 자동/수동 모드
- 센서마다 현재 역할 설명 추가
- 현재 ATmega128 펌웨어의 기존 단일 문자 명령만 사용
  - 사료 모터: a / b
  - 물 펌프: c / d
  - 덮개: e / f / g
  - 약통 A/B: h / i
  - 모드 토글: k
- 물 펌프 1.5초 테스트 및 자동 정지
- 사료 모터 2초 테스트 및 자동 정지
- 덮개 열기 / 닫기 / 정지
- 약통 A/B 스텝모터 각도 입력
  - 현재 펌웨어가 45도 단위이므로 45~360도, 45의 배수만 허용
  - 90도 입력 시 45도 명령을 2회 순차 전송
- 전체 DC 모터 정지 버튼 추가
- 개발자 명령 로그 추가

## 펌웨어 변경 여부

이번 Stage 3는 ATmega128 펌웨어를 변경하지 않습니다.

## Bluetooth 안정성 수정

기존 코드에서 수신 루프와 송신이 하나의 single-thread executor를 공유해, 연결된 동안 송신 명령이 대기열에 막힐 수 있는 구조를 수정했습니다. 수신/연결과 송신 실행기를 분리했습니다.
