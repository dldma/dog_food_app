# Stage 15 - 체중/BCS 기반 권장 급여량 자동 계산

## 입력값

- 체중 (kg)
- 체형(BCS)
  - 정상: BCS 4~5
  - 과체중: BCS 6~7
  - 비만: BCS 8~9
- 중성화 여부
- 사료 열량 (kcal/kg)
- 하루 급여 횟수

## 계산식

```text
MER(kcal/day) = K × BW^0.75
하루 권장 급여량(g) = MER ÷ 사료열량(kcal/kg) × 1000
1회 권장 급여량(g) = 하루 권장 급여량 ÷ 하루 급여 횟수
```

### K 계수

| BCS 구간 | 비중성화 | 중성화 |
|---|---:|---:|
| 정상 4~5 | 103.42 | 96.70 |
| 과체중 6~7 | 81.34 | 82.78 |
| 비만 8~9 | 66.90 | 70.13 |

## 앱 동작

1. 보호자 설정에서 체중, BCS, 중성화 여부, 사료 열량, 하루 급여 횟수를 입력한다.
2. `권장 급여량 계산 및 적용`을 누르면 K, MER, 하루 권장량, 1회 권장량을 표시한다.
3. 자동 계산 모드에서는 1회 권장량을 반올림하여 `기본 1회 급식량`으로 저장한다.
4. 새 생활 예약을 만들 때 이 기본 급식량을 초기값으로 사용한다.
5. 기존 생활 예약의 급식량은 사용자가 설정한 값을 보존한다.

## 예시

10kg / 정상 / 중성화 / 3500 kcal/kg / 하루 2회인 경우:

```text
K = 96.70
MER ≈ 543.8 kcal/day
하루 권장량 ≈ 155.4g
1회 권장량 ≈ 77.7g → 기본 급식량 78g
```

이 기능은 유지 에너지 요구량을 바탕으로 한 초기 권장량 계산이며 의료적 처방량을 의미하지 않는다.
