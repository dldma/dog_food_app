# Stage 10~12 통합 변경사항

장치가 없는 동안 진행할 수 있는 개발을 통합했습니다.

## 1. 장치 없는 개발자 시뮬레이션
- 개발자 도구에 `장치 없이 시뮬레이션` 버튼 추가
- 실제 Bluetooth/ATmega 없이 물/사료 무게, 부족 상태, 덮개, 약 잔여량 UI 확인 가능
- 물 목표량 +/- / 덮개 / 보충완료 / RESET / 자동모드 토글을 가상 상태에 반영
- 개발자 모터 버튼도 실제 출력 없이 가상 센서 상태에 반영
- 시연 급식도 시뮬레이션 상태에서 실행 가능
- 생활 예약은 시뮬레이션 중 실제 휴대폰 시간에 맞으면 생활 급식 실행 기록을 생성
- 실제 Bluetooth 연결이 시작되면 시뮬레이션은 자동 종료

## 2. 생활 급식 실행 이벤트
Stage 5 펌웨어를 확장하여 생활 예약이 실제 실행되면 앱으로 이벤트를 보냅니다.

형식:
`!L,12,0800,65,1,0\n`

최근 10건은 ATmega RAM에 보관합니다. Bluetooth가 끊긴 상태에서 예약이 실행되었더라도 장치 전원이 유지되면 재연결 시 `Q\n` 명령으로 다시 받을 수 있습니다.

## 3. Bluetooth 수신 파서 안정화
- 기존 18자리 `D...` 상태 패킷 유지
- `!L,...` 줄 단위 이벤트를 같은 SPP 스트림에서 함께 처리
- 상태 패킷이 여러 조각으로 나뉘어 들어와도 처리
- 이벤트와 상태 패킷이 붙어서 들어와도 분리

## 4. 생활 급식 기록 개선
- 장치가 실제 실행한 생활 예약을 `생활 급식` 기록으로 저장
- 사료 `배출 설정량`과 투약 수량을 기록
- 휴대폰이 연결되지 않아 식후 무게를 확인하지 못한 경우 `추정 섭취량 미측정`으로 표시
- 추정치를 실제 섭취량처럼 임의로 기록하지 않음
- V2/예전 기록 파일과 호환 유지, 새 기록은 V3 형식 사용

## 5. 아직 실제 장치가 필요한 항목
- HC-05/HC-06 연결 확인
- 센서 실측값 보정
- 각 모터 방향/동작 시간 확인
- 생활 예약의 실제 무연결 실행 확인
- 자동급수 실물 검증
- 장시간 운전 안정성 확인
