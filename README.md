# Dog Food - 졸업작품 Android 앱

현재 기준은 **Stage 2 보호자용 홈 UI**입니다. 기존 App Inventor 동작을 Android/Kotlin으로 유지하면서 단계적으로 생활/시연/개발자 모드를 통합합니다.

# Dog Food - App Inventor 블록 리팩터링 버전

업로드된 MIT App Inventor 블록 스크린샷을 기준으로 Android/Kotlin 코드로 다시 구성한 프로젝트입니다.

## 반영한 핵심 동작

- Bluetooth Classic(SPP) 연결 및 수신
- 18글자 `D...` 상태 패킷 파싱
- 물 설정량 / 현재 물 / 현재 사료 / 알약 잔여량 표시
- 사료·물·알약 부족 상태 표시
- 덮개 열림/닫힘 상태 표시
- 물 섭취량 = `water_eat * 30`
- 알약 A/B 섭취량 = `7 - 잔여량`
- 수동 명령
  - 물 증가 `o`
  - 물 감소 `p`
  - 덮개 닫힘 `e`
  - 덮개 열림 `f`
  - 보충완료 `m`
  - RESET `j`
- 급식 시 `wx{사료}y{알약A}z{알약B}\n` 전송
- TTS: `이름아/야, 밥먹자.` 및 섭취량 업데이트 알림
- 급식 후 사료 섭취량 계산
- 기록을 `애견급식기.txt`에 저장
- 설정/기록 화면 분리

## 사진에서 잘려 있어 추정한 부분 2개

원본 블록 스크린샷에 `start.Click` 하단과 3번째 급식 후반이 잘려 있습니다.
따라서 아래 두 값은 한 곳에 상수/로직으로 분리해 수정하기 쉽게 해 두었습니다.

1. 시작 명령: `DogFoodProtocol.CMD_START = "i"`
2. START 클릭 시 테스트 예약 시각: 현재 시각 기준 `+1분`, `+4분`, `+7분`
   - 사진에서 +1, +4는 확인됨
   - +7은 동일한 3분 간격 패턴으로 추정
3. 섭취량 측정 지연
   - 1번: +2분 (사진 확인)
   - 2번: +1분 (사진 확인)
   - 3번: +1분 (사진 미확인, 2번 패턴 적용)

`.aia` 원본 또는 ATmega 송수신 코드가 있으면 이 추정값까지 1:1로 맞출 수 있습니다.

## 실행

1. Android Studio에서 이 폴더를 Open
2. Gradle Sync
3. Android 휴대폰 연결
4. HC-05/HC-06 등의 블루투스 모듈을 휴대폰 설정에서 먼저 페어링
5. 앱 실행 → `블루투스 연결` → 페어링 기기 선택

Android 12 이상에서는 앱 최초 실행 시 Bluetooth 권한을 허용해야 합니다.

## Stage 5

생활 모드를 추가했습니다. 사용자가 매일 반복할 급식 예약을 최대 10개까지 저장할 수 있으며,
Bluetooth 연결 시 휴대폰 현재 시간과 저장된 예약을 Stage 5 ATmega 펌웨어로 자동 동기화합니다.
RTC가 없으므로 장치 전원 재인가 후 앱과 한 번 연결해야 합니다.

## 2026-09-22 물 상태/자동 급수 수정

- 물통 수위 센서와 물그릇 로드셀 상태를 앱에서 각각 표시
- 물그릇 무게가 0g/음수여도 물통 부족으로 오판하지 않도록 펌웨어 분리
- 기본 물 유지량 100g
- 물그릇이 유지량보다 30g 낮아지면(기본 70g 미만) 급수를 시작하고 100g까지 채움
- 메인 화면의 `-10g / +10g` 사이에 현재 유지 설정값을 항상 표시
- 유지량 변경 시 자동 급수 시작 기준도 `현재 유지량 - 30g`으로 함께 표시

## 2026-09-23 권장 급여량 자동 계산 추가

- 체중 + BCS(정상/과체중/비만) + 중성화 여부 + 사료 열량(kcal/kg) 입력
- `MER = K × BW^0.75` 계산
- 하루 권장 급여량과 하루 급여 횟수 기준 1회 권장량 계산
- 자동 계산 모드에서 계산된 1회 권장량을 기본 급식량에 적용
- 이전 버전의 kcal/g 저장값은 kcal/kg로 자동 변환하여 불러옴
- 계산 로직: `FeedingCalculator.kt`
